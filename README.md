# AI-Powered Computer Vision Projects using Python

## Projects Included

### 1. Face Detection
- Detects human faces in real time
- Uses OpenCV Haar Cascade / DNN
- Webcam support

### 2. Age and Gender Detection
- Predicts age group and gender from live camera
- Uses pretrained Deep Learning models
- Real-time inference

### 3. Object Detection
- Detects multiple objects in real time
- Displays object labels and confidence scores
- Uses OpenCV DNN with pretrained models

## Technologies Used
- Python
- OpenCV
- NumPy
- Deep Learning (DNN)
- Webcam

## Features
- Real-time detection
- Easy to run
- Beginner-friendly
- Modular project structure
